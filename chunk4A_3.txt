because there are not many outliers in the data. If the number of outliers
increased, the k-medoid would output a better solution.
Therefore, we can conclude our clustering analysis with the following insights.
When we want to perform segmentation, we can use a clustering algorithm such
k-means or k-medoid. W e use clustering because our data are unlabeled (i.e.,
they do not have an outcome label). In the example, we find that when amount
spent and patronage duration are used and we ask for three clusters, we can
obtain the average characteristics of customers in the three clusters. The
differences between these customers inform us how the business can present
effective product of ferings to customers in these three segments.
5.6 IMPLEMENTATION USING R: SEGMENTATION
USING K-MEANS AND K-MEDOID
To analyze and plot data, we will use two packages: cluster3 and
factoextra .4 After importing the data, we center and scale it using the
scale()  function with center = TRUE  and scale = TRUE  options; center
= TRUE  subtracts the column means of a variable from their corresponding
column values, and scale = TRUE  divides the (centered) columns of a variable
by their standard deviations. This process converts values of each variable into
their z scores. This is an important step before cluster analysis since each
variable of a dataset can be measured on dif ferent scales. In our dataset, for
example, duration of store patronage is measured in months, but amount spent is
measured in dollars. Scaling the data ensures that there are no distortions due to
difference in scales used across variables.
Once we have read and scaled the data (df) , the actual code to run k-means is
quite simple. In the kmeans()  function, centers specifies the number of clusters (
k), then nstart = 25  sets 25 initial random centroids and selects the best one.
A higher value of nstart  gives more stable solutions, but for larger datasets this
may end up taking more computing time.
library(cluster)
library(factoextra)
 
set.seed(12345) #Set seed for reproducibility
 
df <-  read.csv(url(
"http://data.mishra.us/files/chapter_segmentation/segmentation_kmeans.csv "))
 
df <- scale(df,center = TRUE, scale = TRUE)
 
k_means <- kmeans(df, centers = 3, nstart = 25)
The following code helps produce Figure 5.4  using fviz_cluster()  function.
repel = TRUE  prevents datapoints from lumping together and makes them
readable.
fviz_cluster(k_means, data = df,
 repel = TRUE,
 main = "k-means segmentation plot"
) 
We can also print cluster centers for each of the three clusters, as we saw in
Figure 5.4 . This is very helpful when our data have more than two variables and it
becomes harder to plot clusters. By using cluster centers, we can assess the
average characteristics of each cluster . Consistent with the plot, here our output
shows that members of cluster 1 have an average patronage duration of −1.009
months and have spent $1.383, whereas members of cluster 2 have a patronage
length of −1.006 months and have spent −$1.397. Due to centering and scaling,
amount spent and length have negative values. Cluster numbers might change in

Silhouette , a tool to detect the quality of clusters, can help in estimating the right
value of k. The silhouette coef ficient varies between −1 and +1. An average value
(also known as average silhouette width) near 1 shows a tight cluster , with
observations within a cluster close together compared to observations between
clusters. As the value moves away from +1 to −1, it indicates reduced within-
cluster cohesion.
The following code calculates distance and generates silhouette plots, as we saw
in Figure 5.5 . The dist()  function calculates the Euclidean distance between
points (method="euclidean") .
dis=dist(df, method="euclidean")
sil = silhouette (k_means$cluster, dis)
plot(sil,main=paste("K-Mean k = ", 3))
The silhouette plot shows that the average silhouette width is 0.58. W e can try
different values of k (or centers  in the k-means calculation) to see how the
average silhouette width changes.
The following code performs k-medoid clustering on the same data. There are
only two dif ferences in this code compared to the one that produces k-means.
First, instead of the k-means()  function, we use pam() , which stands for
“partitioning around medoids.” Second, for cluster analysis and calculation of
silhouette width, we use Manhattan distance. This produces the cluster plot and
silhouette width we saw in Figures 5.6  and 5.7.
k_medoid <- pam (scale(df), k = 3, metric = "manhattan")
 
fviz_cluster(k_medoid, data = df,
 repel = TRUE,
 main = "k-means segmentation plot"
)
 
dis=dist(df, method="manhattan")
sil = silhouette (k_medoid$clustering, dis) # for
silhouette plots
plot(sil, main=paste("K-Medoid k = ",3))
Since there are not many outliers, the results of k-means and k-medoid are very
similar .
